# คู่มือการใช้งานสคริปต์ Lua แยกทั้ง 5 ส่วน

ไฟล์ภายในชุดบีบอัดนี้ถูกแยกออกเป็น 5 ส่วนตามลำดับการทำงาน:
1. `Part1_UICore.lua` — โครงสร้าง UI หลัก (ขนาด 600x800 โทนสีม่วง-น้ำเงิน-ดำ), แถบด้านบน, ปุ่มมุมขวาบน `[—][🔳][❎]` และลูกบอลลอยน้ำวงกลมขอบสีดำ
2. `Part2_ScriptUI1.lua` — สคริปต์ UI 1 สำหรับตั้งชื่อค่าย, คำว่า `by ชื่อผู้จัดทำ`, ลิงก์ใต้คำว่าผู้จัดทำ และระบบรับเพื่อน (`ui:AddFriend`)
3. `Part3_ScriptUI2.lua` — สคริปต์ UI 2 สำหรับตั้งค่าโลโก้ลูกบอลลอยน้ำ และลิงก์ Logo Icon ใน UI
4. `Part4_MessageAndFunctionTab.lua` — สคริปต์ Message และระบบสร้าง Tab + ลงทะเบียน Function
5. `Part5_PingPongRelay.lua` — ระบบวงจรสลับลิงก์ตีกลับไปมาระหว่าง UI 1 และ UI 2 (`StartPingPongRelay` / `StopPingPongRelay`)

### วิธีใช้งาน
ให้รันหรือ `loadstring` เรียงตามลำดับตั้งแต่ **Part 1 -> Part 2 -> Part 3 -> Part 4 -> Part 5** เพื่อให้แต่ละส่วนส่งต่อค่า `_G` เชื่อมโยงกันครบสมบูรณ์ครับ
